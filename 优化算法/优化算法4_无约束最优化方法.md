# 无约束最优化方法

## 基本问题

**基本迭代公式**:$X^{k+1}=X^k+\alpha_k S^k,k=1,2,3,...$

**基本问题**:选择搜索方向$S^k$

## 共轭梯度法

### 梯度法

梯度法选定的搜索方向即为函数的负梯度方向，即$S^k=-\nabla f(X^k)$，$X^{k+1}=X^k-a_k\nabla f(X^k)$，其中$a_k$为最优步长因子，是第$k$轮一维搜索的目标。

![image-20261021164356217](./assets/image-20261021164356217-1792572237987-1.png)

根据一维搜索，其搜索的结果一定与某等值线相切。在此处作为下一次搜索方向的的负梯度则一定与上次的搜索方向垂直。

特点：

1. 相邻两迭代点的梯度是彼此正交的，相邻的搜索方向相互垂直。
2. 向极小点的逼近路径是一条曲折的锯齿形路线，而且越接近极小点，前进速度越慢。
3. 离极小点较远时，一次迭代得到的函数下降量较大。
4. 目标函数的性态、初始点的位置，收敛速度影响较大。

迭代步骤：

1. 给定初始点 $X^0$ 和收敛精度 $\varepsilon$，置 $k=0$。
2. 计算梯度，并构造搜索方向 $S^k=-\nabla f(X^k)$。
3. 一维搜索，求新的迭代点：$\min f(X^k-\alpha\nabla f(X^k))\rightarrow\alpha_k$，$X^{k+1}=X^k-\alpha_k\nabla f(X^k)$。
4. 收敛判断：若满足 $\lVert\nabla f(X^{k+1})\rVert\le\varepsilon$，则令 $X^*=X^{k+1}$，$f(X^*)=f(X^{k+1})$，终止计算；否则令 $k=k+1$，转第 2 步继续迭代。

### 共轭梯度法

#### 

**共轭**:设$H$为$n×n$阶实对称正定矩阵，如果有两个$n$维非零向量$S_1$与$S_2$，满足$S_1^T H S_2=0$，则称向量$S_1$与$S_2$关于矩阵$H$共轭。

**共轭向量（组）**:若非零向量组$S_1,S_2,...,S_n$满足$S_i^THS_j=0$，则这组向量为$H$的一组共轭向量。若$H$为单位矩阵，则这组向量相互正交。

**共轭方向性质**:

（1）对于正定二次函数，从任意初始点 $X^0$ 出发，依次沿一组（$n$ 个）共轭方向一维搜索，最多 $n$ 次即可达到极小点。

**共轭方向法**：使用一组共轭方向进行连续的一维搜索得到极小值点。

**推论**：不同的初始点，不同的共轭方向组，不影响收敛性。

（2）从任意两点 $X_1^0$ 和 $X_2^0$ 出发，分别沿同一方向 $S^0$ 进行一维搜索，得到两个一维极小点 $X_1^1$ 和 $X_2^1$，则连接此两点所形成的向量 $S^1=X_1^1-X_2^1$，$S^1$ 与原方向 $S^0$ 关于该函数的 Hessian 矩阵相共轭。

设 $A$ 为 $n\times n$ 阶实对称正定矩阵。

（3）若 $S_i\ (i=1,2,...,n)$ 为关于矩阵 $A$ 共轭的一组非零向量组，则这一组向量线性无关。

**推论**：在 $n$ 维空间中相互共轭的非零向量的个数不超过 $n$ 个。

（4）设向量 $S_i^{(1)}\ (i=1,2,...,n)$ 是一组线性无关的非零向量，则可构造出 $n$ 个非零向量 $S_i^{(2)}\ (i=1,2,...,n)$，使其满足

$$S_i^{(2)T}AS_j^{(2)}=0,\quad i\ne j,\ i,j=1,2,...,n$$

**推论**：可由坐标轴方向来构造共轭向量。

共轭梯度法的搜索方向基于共轭方向对负梯度方向进行修正，即$S^{k+1}=-\nabla f(X^{k+1})+\beta_kS^k$，其中根据共轭条件可得$\beta_k=\frac{\lVert  \nabla f(X^{k+1}) \rVert^2}{\lVert  \nabla f(X^{k}) \rVert^2}$，即$S^{k+1}=-\nabla f(X^{k+1})+ \frac{\lVert  \nabla f(X^{k+1}) \rVert^2}{\lVert  \nabla f(X^{k}) \rVert^2} S^k$。

迭代步骤：

1. Given $X^0$ and convergence accuracy $\varepsilon>0$.
2. Calculate $S^0=-\nabla f(X^0)$; set $k=0$.
3. Compute $\alpha_k$: $f(X^k+\alpha_kS^k)=\min f(X^k+\alpha S^k)\Rightarrow\alpha_k$.
4. $X^{k+1}=X^k+\alpha_kS^k\Rightarrow$ calculate $\nabla f(X^{k+1})$.
5. Convergence Judgement: if $\lVert\nabla f(X^{k+1})\rVert\le\varepsilon$, terminate the algorithm, and the optimal solution is $X^*=X^{k+1}$; otherwise continue searching.
6. If $k=n$, set $X^0=X^{k+1}$, return to Step 2; otherwise continue searching.
7. Compute $\beta_k$, and $S^{k+1}=-\nabla f(X^{k+1})+\beta_kS^k$.
8. Let $k=k+1$, return to Step 3.

## 牛顿法

### 基本牛顿法

直接用一个二次函数拟合原优化函数，直接用新函数的最优点为下一次迭代点。即搜索方向为$S_k=-[H(X^k)]^{-1}\nabla f(X^k)$，其中$H(X^k)$为该点的Hessian矩阵，同时无需一维搜索，最优化步长因子始终为$1$。

特点:

（1）对于正定二次函数，$X^{k+1}$ 是精确极小点，方向 $S^k$ 直指函数的极小点。

（2）用基本牛顿法求解正定二次函数时，无论从哪个初始点出发，计算所得牛顿方向直指极小点，而且步长等于 $1$。

（3）对于一般非线性函数，点 $X^{k+1}$ 只是原函数的一个近似极小点。故将此点作为下一个迭代点 $X^{k+1}$。

（4）但是对于非正定函数，由上式得到的点 $X^{k+1}$，不能始终保持函数的下降性，基本牛顿法有可能失败。如图所示。

### 阻尼牛顿法

与牛顿法相比，引入可变的最优化步长因子，称为阻尼因子，而搜索方向不变，即$S_k=-[H(X^k)]^{-1}\nabla f(X^k)$，且$X^{k+1}=X^k+a_kS^k$。

迭代步骤:

1. Given $X^0$ and convergence accuracy $\varepsilon>0$; set $k=0$.
2. Compute $\nabla f(X^k)$, $\nabla^2f(X^k)$ and $[\nabla^2f(X^k)]^{-1}$.
3. Choose $S^k=-[\nabla^2f(X^k)]^{-1}\nabla f(X^k)$ as the search direction.
4. Develop 1-D search and determine the optimal step length $\alpha_k$, identify the new iteration point $X^{k+1}=X^k+\alpha_kS^k$.
5. Convergence Judgement: if $\lVert\nabla f(X^{k+1})\rVert\le\varepsilon$, search can be terminated and the optimal solution is $X^*=X^{k+1}$; otherwise continue searching.
6. Let $k=k+1$, return to Step 2.

特点:

（1）构造搜索方向利用了函数的所有的一阶导数和二阶导数，产生的搜索方向直指极小点。

（2）对于正定二次函数，从任意初始点出发，一次迭代即可得到极小点。对于一般函数，迭代的次数比其它算法都要少。

（3）每次迭代都需要计算函数的二阶导数矩阵及其逆矩阵。计算量大，计算时间长，计算速度较慢。

（4）计算中，用差分代替微分。所得梯度和二阶导数矩阵，以及求得的牛顿方向都存在较大误差。

## 变尺度法（DFP）

变尺度法为拟牛顿法的一种，基本思想为构造一个矩阵，使其在计算中以递推的形式趋近$[H(X^k)]^{-1}$。

**迭代公式**：$X^{k+1}=X^k-\alpha_kA^k\nabla f(X^k)$，即 $X^{k+1}=X^k-\alpha_kS^k$。

当 $A^k=I$ ——梯度法的迭代公式。

当 $A^k=[H(X^k)]^{-1}$ ——阻尼牛顿法的迭代公式。

在迭代中，$A^0=I$，故第一步用梯度法，然后逐步逼近牛顿方向。

**变尺度方向**：$S^k=-A^k\nabla f(X^k)$

**变尺度矩阵**：$A^{k+1}=A^k+E^k$

**校正矩阵**：

$$E^k=\frac{\Delta X^k[\Delta X^k]^T}{[\Delta g^k]^T\Delta X^k}-\frac{A^k\Delta g^k[\Delta g^k]^TA^k}{[\Delta g^k]^TA^k\Delta g^k}$$

式中，$\Delta X^k=X^{k+1}-X^k$，$\Delta g^k=\nabla f(X^{k+1})-\nabla f(X^k)$。

迭代步骤:

1. 给定 $X^0$ 和收敛精度 $\varepsilon>0$。
2. 计算 $\nabla f(X^0)$，取 $A^0=I$，置 $k=0$。
3. 构造搜索方向 $S^k=-A^k\nabla f(X^k)$。
4. 进行一维搜索，得到 $\alpha_k$ 和迭代点 $X^{k+1}=X^k+\alpha_kS^k$。
5. 收敛判断：若 $\lVert\nabla f(X^{k+1})\rVert\le\varepsilon$，则令 $X^*=X^{k+1}$，$f(X^*)=f(X^{k+1})$，终止计算；否则继续下一步。
6. 若 $k<n-1$，继续下一步；若 $k=n-1$，令 $X^0=X^{k+1}$，返回第 2 步。
7. 计算 $\nabla f(X^k)$、$\Delta X^k$、$\Delta g^k$、$E^k$，构造新的变尺度矩阵 $A^{k+1}=A^k+E^k$，置 $k=k+1$，返回第 3 步。

## 鲍威尔法

根据共轭方向的性质：从任意两点 $X_1^0$ 和 $X_2^0$ 出发，分别沿同一方向 $S^0$ 进行一维搜索，得到两个一维极小点 $X_1^1$ 和 $X_2^1$，则连接此两点所形成的向量 $S^1=X_1^1-X_2^1$，$S^1$ 与原方向 $S^0$ 关于该函数的 Hessian 矩阵共轭。

将平行搜索特性推广到 $n$ 维：

设 $X_1^0$、$X_2^0$ 是 $R^n$ 中的两个不同点，$\{S_1,S_2,...,S_l\}$ 是 $R^n$ 中一组线性无关的方向，定义如下两个平行的线性簇

$$L_1=\left\{X_1^0+\sum_{i=1}^{l}\alpha_iS_i\mid\alpha_i\in R,\ i=1,2,...,l\right\}$$

$$L_2=\left\{X_2^0+\sum_{i=1}^{l}\alpha_iS_i\mid\alpha_i\in R,\ i=1,2,...,l\right\}$$

如分别用 $X_1^1$ 和 $X_2^1$ 表示 $f(X)$ 在 $L_1$ 和 $L_2$ 上的极小点，那么 $X_1^1-X_2^1$ 与 $S_1,S_2,...,S_l$ 共轭。
